# Screenshots

This directory holds PNG/SVG screenshots of DiskInventory's UI surfaces,
regenerated by `spec/build_screenshots.py`.

## Files

| File | Source | Captures |
|---|---|---|
| `01-dashboard.svg` | `disk-inventory.py serve <run-dir>` | live dashboard tiles, categories, top-N, journal tail |
| `02-categories.svg` | (reserved — same run as 01) | cropped Categories + Heavy-caches area |
| `03-fleet-dedup.svg` | `fleet-dedup.html` opened in a browser | cross-host SHA-1 dedup table |
| `04-override-ui.svg` | `inventory.html` opened in a browser | the offline override-UI in inventory.html |

When Playwright is installed, the harness writes real PNG screenshots
with these basenames (`.png`); without it, it writes SVG placeholders
that mirror the dark dashboard chrome. Both render inline on GitHub.

## Regenerating

```bash
pip install playwright
playwright install chromium

# Real screenshots — need a recent run dir + a fleet dir
python spec/build_screenshots.py

# Skip the heavy fleet step
python spec/build_screenshots.py --only 1
python spec/build_screenshots.py --only 3
```

If Playwright isn't installed, the script writes SVG placeholders so the
README gallery still has something to render — the SVG mirrors the dark
dashboard chrome and tiles.
